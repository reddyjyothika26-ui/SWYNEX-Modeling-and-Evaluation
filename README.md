 Task 3: Machine Learning Model

This project uses a K-Nearest Neighbors (KNN) model to predict Iris flower species using Python and Scikit-learn.

 Features
- Trained a baseline classification model.
- Evaluated accuracy, precision, recall, and F1-score.
- Visualized predictions using a confusion matrix.
- Discussed model limitations.

 Result
Achieved 93.3% test accuracy on the Iris dataset.

 Tools Used
Python, Pandas, Matplotlib, Scikit-learn, and Jupyter Notebook.
